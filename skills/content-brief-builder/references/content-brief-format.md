# Brief 输出格式

本文件定义 `content-brief-builder` 的输入和输出格式。
在 `content_system` 主链路里，最终输出必须兼容 `docs/stage1-brief-template.md`，因此不能直接输出自由 YAML。

## topic-pool.md（可选输入）

如果选题来自外部选题池，可按以下格式读取：

```yaml
生成时间: string                      # ISO 日期
目标读者: string                      # 本次选题面向谁
候选题目:
  - 题目: string
    一句话判断: string                # 为什么这个题现在值得做
    原始信号:
      平台: string
      证据: string
    建议角度: string                  # 怎么讲，不复述原热点
    推荐钩子: string                  # 适合作为开头的冲突句
    综合评分: number                  # 0-16
    评分档位: 立刻做|补搜后做|观察|丢弃
    可延展形态:
      - string                       # 文章/口播/朋友圈/小红书
```

## content-production/inbox/YYYYMMDD-<slug>-gzh-brief.md（主链路输出）

由 `content-brief-builder` 输出，结构必须和 `stage1-brief-template.md` 保持一致。


## 字段映射原则

| 方法论字段 | 主链路落点 |
|------------|-----------|
| 目标读者 | `基础信息.target_reader` |
| 核心判断 / 切入角度 | `核心观点` |
| 写作目的 | `基础信息.publish_goal` + `核心观点` |
| 推荐框架 | `备注` 中说明 |
| 素材清单 | `可用案例 / 素材` |
| SCQA | `SCQA 结构` |
| 风险提醒 | `风险提醒` |

## 约束

- 原有 9 个 section 名称一个都不能改
- 新信息只能追加到 `SCQA 结构`、`风险提醒`、`素材来源可信度` 或 `备注`
- 如果某条素材来自知识推断，必须在内容里标注“待验证”
