# Brief 质量标准

## 最关键的字段：切入角度

角度决定这篇文章跟别人有什么不同。

### 好角度

- 一句话说清楚
- 有明确立场（不是"这件事有两面性"）
- 跟已有内容不一样
- 有数据或经验支撑

好角度示例：
- "大多数人用 AI 做内容失败，不是因为工具不行，是因为没有质量文化"
- "公众号还值得做，但做法要变——从写文章变成搭流水线"

### 烂角度

- "AI 工具的全面介绍"（没有立场）
- "关于XX你需要知道的一切"（维基百科不是角度）
- "XX的最佳实践"（谁都能写的废话）

### 检验方法

两个不同写手拿到这份 brief，能写出方向一致的文章吗？不能 = 角度不够具体。

## 三种通用选题公式

### 公式一：痛点 + 工具 + 收益

- 模板：`[痛点] + 用[AI工具/方法] + 获得[具体收益]`
- 示例：`每天写周报要花 1 小时？用 ChatGPT 3 分钟搞定。`
- 适合：教程类、清单类、转化类内容

### 公式二：误区 + 反转 + 方法

- 模板：`你以为[误区]？错，其实是[反转]，我来教你[方法]`
- 示例：`你以为 AI 会取代你的工作？错，真正取代你的是会用 AI 的人。`
- 适合：观点类、辟谣类、热点评论类内容

### 公式三：低效动作 + AI 替代 + 效果对比

- 模板：`别再[低效动作]了，用[AI方法]，效果[对比]`
- 示例：`别再手动排版 PPT 了，用 AI 30 秒出第一版。`
- 适合：效率类、工具类、案例类内容

## 热点七步法

1. 收集信息：至少看 2-3 个信源，优先官方发布、权威数据、原始报道
2. 确定角度：不要复述新闻，改写成“这对目标读者意味着什么”
3. 列出要点：先写 3-5 个核心点，再决定是否值得展开
4. AI 加速：让 AI 总结资料、列提纲、补争议点，但由人拍板观点
5. 快速制作：热点重时效，先完成再润色
6. 标题点明热点：热点关键词和你的判断都要出现
7. 发布扩散：先发私域或朋友圈，借前期扩散拿种子流量

## 选题四维打分

在多个方向里做取舍时，用 1-5 分简单评估：

| 维度 | 要问自己的问题 |
|------|----------------|
| 热爱程度 | 我真的愿意持续讲这个题吗？ |
| 专业能力 | 我能比目标读者多讲明白 10% 吗？ |
| 市场需求 | 这个痛点真实存在，且人群足够大吗？ |
| 资源积累 | 我有案例、经历、人脉或数据支撑吗？ |

## Brief 反模式

| 反模式 | 问题 | 修复 |
|--------|------|------|
| "写一篇关于XX的全面指南" | 没有角度 | 定义具体立场 |
| 缺少读者定义 | 写手猜读者 | 写明具体读者画像 |
| 没有素材来源 | 写手编事实 | 至少 3 条可追溯素材 |
| 角度像维基百科 | 不是角度 | 找独特的、有争议的视角 |
| "所有人都应该看" | 读者太泛 | 缩窄到某一类人 |
| 复述热点标题 | 没有自己的角度 | 翻译成"这对读者有什么用" |
| 没有风险提醒 | 不知道哪里翻车 | 至少 1 个潜在风险 |
| 热点题只复述新闻 | 没有自己的判断 | 改写成“这对目标读者有什么用” |
| 只有工具没有收益 | 读者感受不到价值 | 把结果写具体：省时、省钱、避坑、涨粉、转化 |

## 6 项自检（输出前必须全过）

1. [ ] 角度够硬？（一句话、有立场、与众不同）
2. [ ] 读者够具体？（不是"所有人"）
3. [ ] 素材够硬？（至少 3 条，每条有来源）
4. [ ] 框架选对？（和内容类型匹配）
5. [ ] 有风险意识？（至少 1 个翻车点）
6. [ ] SCQA 完整？（情境、冲突、问题、答案都有内容）

任何一项不通过，回去修改后再输出。

## 热点题附加自检

如果这是热点题，再补查 3 项：

1. [ ] 是否明确写出了热点关键词？
2. [ ] 是否给出了“对目标读者有什么用”的解释？
3. [ ] 是否说明了风险边界或反转可能？
