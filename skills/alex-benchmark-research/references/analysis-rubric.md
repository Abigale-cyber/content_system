# Analysis Rubric

## 1. Account Structure

Answer:

- What is the one-line positioning?
- Who is the target audience?
- What core promise keeps the audience returning?
- What are the main content pillars?
- What is the likely conversion path?

## 2. Recurring Columns

Look for repeatable columns such as:

- tool reviews
- workflow tutorials
- trend commentary
- case breakdowns
- weekly roundups
- myth-busting
- FAQ

For each column, capture:

- column name
- purpose
- sample count
- frequency
- series signal

## 3. Narrative Patterns

Extract recurring:

- hook types
- structural patterns
- proof styles
- CTA styles

Typical hook types:

- result-first
- anti-common-sense
- pain-first
- question-led
- trend peg
- identity resonance

## 4. Topic Density

Measure:

- which topics appear most often
- which topics are rising in 30/60/90 day windows
- which topics likely serve traffic, trust, authority, or conversion
- which topics cluster around high engagement

## 5. Timeliness

Tag findings:

- `Evergreen`
- `Verify-Now`
- `Legacy-2024`

`Verify-Now` applies to:

- platform mechanism claims
- tool/model names
- pricing
- deployment paths
- extension/plugin recommendations

`Legacy-2024` applies to:

- explicitly 2024 trend decks
- obsolete model stacks
- old bot deployment workflows
- screenshot-driven setup paths from a different ecosystem state

## 6. Alex Recommendation Layer

Always end with:

- `borrow`
- `adapt`
- `avoid`
