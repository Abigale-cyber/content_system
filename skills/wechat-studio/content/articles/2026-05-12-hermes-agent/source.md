有句话我最近越听越想笑：

“OpenClaw 是养虾，Hermes Agent 是养马。”

这个梗很有传播感，也确实好玩。但问题是，很多人现在连马厩门都没打开，就已经开始讨论马术比赛了。

很多安装教程命令很完整，步骤也没错，但对小白来说，还是太像技术文档。你让他复制命令、刷新 shell、配置模型、看 doctor 报告，他只会觉得：这不是养马，这是先让我去学马兽医。

更简单的做法是：**打开 Codex，把 Hermes 的项目地址和安装要求发给它，让它按官方文档帮你跑第一遍。**

这里说 Codex，只是因为我自己用它演示。只要你的 AI IDE 能读文件、执行命令、查看终端结果，比如 Cursor、Claude Code、Trae 等，也可以照这个方法来。

你不用先学会终端，也不用理解每一条命令。你要做的是把任务说清楚：要装什么、从哪里装、哪些事情不能乱做、最后怎么验收。Codex 负责看文档、跑命令、处理报错；遇到授权、密钥、扫码这类必须你本人操作的步骤，再停下来叫你确认。

## 最快路径：先让 Codex 完成最小闭环
如果你已经有 Codex Desktop，先别急着研究一堆命令。你可以手动准备一个安装任务书，也可以直接让 Codex 帮你新建文件夹和文档。

保守一点的做法，是先在电脑上新建一个空文件夹，比如：

```latex
Hermes-Install
```

为什么要新建空文件夹？因为这样安全、干净。Codex 做了什么，你更容易看清楚；它就算生成日志或临时文件，也不会混进你原来的工作资料里。

然后在这个文件夹里新建一个 Markdown 文件，文件名叫：

```latex
INSTALL_HERMES_BY_CODEX.md
```

如果你连新建文件夹和文档也不想自己做，也可以直接让 Codex 代办。你可以先对它说：

```latex
请在当前目录下新建一个 Hermes-Install 文件夹，并在里面创建 INSTALL_HERMES_BY_CODEX.md，把下面这段安装任务书写进去。只操作这个新文件夹，不要改动其他文件。
```

接着，把下面这段内容完整放进 `INSTALL_HERMES_BY_CODEX.md`：

```latex
请帮我在这台电脑上安装 Hermes Agent。
项目地址是：https://github.com/NousResearch/hermes-agent

请先判断我的电脑系统是 macOS、Linux、Windows 还是 WSL2，然后根据 Hermes 官方文档选择合适的安装方式。
不要自己编安装方法，优先使用官方 README 或官方安装脚本。

每执行一步前，先用中文告诉我你准备做什么。
每执行完一步，用中文解释执行结果。

安全要求：
1. 不要删除我的文件；
2. 不要清空任何目录；
3. 不要修改和 Hermes 无关的配置；
4. 不要在聊天里明文展示我的 API Key、token、密码等敏感信息。

安装完成后，请依次验证：
1. hermes --version 能不能显示版本；
2. hermes model 能不能进入模型配置；
3. hermes doctor 能不能正常跑体检；
4. hermes chat -q "请用一句话说明你现在是否可以正常工作。" 能不能得到回复。

如果中间报错，不要直接重装。先解释报错原因，再给我最小修复方案。
```

这段话的核心不是“教你命令”，而是把目标、边界和验收标准一次性交代清楚。小白最怕的不是慢，而是装到一半不知道 Codex 在干什么，也不知道它到底装好了没有。

## 打开 Codex，然后把任务交给它
接下来，用 Codex 打开刚才的 `Hermes-Install` 文件夹。你也可以在一个干净的安装目录里启动 Codex，让它自己创建 `Hermes-Install` 和安装任务书。

如果 Codex 问你是否允许访问文件、执行命令，要认真看权限说明。第一次安装 Hermes，建议优先授权当前安装文件夹和必要的命令执行权限。只有当你明确知道 Hermes 需要访问更多目录，或者后续要让它处理其他文件时，再扩大权限范围。

打开文件夹以后，直接发这句话：

```latex
请阅读 INSTALL_HERMES_BY_CODEX.md，按里面的要求帮我安装 Hermes Agent，配置模型，并完成测试。如果我要接微信，请引导我扫码绑定。过程中不要泄露我的密钥，不要删除文件，不要修改和 Hermes 无关的配置。
```

如果你明确想优先使用 Codex / OpenAI 相关模型，可以再补一句：

```latex
优先使用我系统里已经登录的 Codex/OpenAI Codex 模型；如果不可用，再引导我选择其他模型服务商。
```

正常情况下，Codex 会先判断你的系统环境，然后按官方文档安装 Hermes。过程中你可能会看到它运行这些命令：

```bash
hermes --version
hermes model
hermes doctor
hermes chat -q "请用一句话说明你现在是否可以正常工作。"
```

你不需要理解每一行命令。你只需要盯住结果：电脑能不能识别 Hermes，模型配置入口能不能打开，`hermes doctor` 有没有明显错误，最后能不能正常回复一句话。

## 安装过程中，你只盯三件事
第一，**Codex 每一步执行前要先解释。**

如果它上来就跑一串命令，你可以直接打断：

```latex
等一下。每一步执行前，先用中文告诉我这一步是干什么的，执行后可能会改变什么。
```

第二，**遇到报错，先解释，不要直接重装。**

你可以这样说：

```latex
先不要重装。请解释这个报错是什么意思，然后给我最小修复方案。
```

第三，**安装结束以后必须验收。**

让 Codex 依次检查下面四件事。

先跑：

```bash
hermes --version
```

如果能显示 Hermes 的版本号，说明电脑已经能识别 `hermes` 这个命令。

再跑：

```bash
hermes model
```

如果能进入模型配置界面，说明 Hermes 可以开始选择或填写模型服务。注意，这一步不等于模型已经配置成功，只是说明配置入口能打开。

接着跑：

```bash
hermes doctor
```

如果能完成体检，并且没有明显的红色报错，说明基础环境大概率没问题。

最后，再跑一次真正的对话测试：

```bash
hermes chat -q "请用一句话说明你现在是否可以正常工作。"
```

如果 Hermes 回复了类似下面这样的话：

```latex
我现在可以正常工作，可以接收你的问题并给出回复。
```

就说明它不只是“装上了”，而是真的能调用模型并完成一次对话。

Hermes 的回复不一定和上面一字不差。你只要看三点：有没有回复、是不是在回答你的问题、是不是一条正常的人话。
如果这里出现 API Key 错误、模型不可用、网络连接失败，说明安装可能没问题，但模型配置还没有真正完成。

## 如果要接微信，让 Codex 带你扫码
以当前常见接入方式看，Hermes 接微信通常不是把你的个人微信号变成机器人，而是通过 Weixin / iLink Bot API 接入一个 bot 身份。你可以理解成：Hermes 在微信里多了一个入口，你能给它发消息，让它帮你干活。具体以 Hermes 官方文档和安装向导为准。

让 Codex 运行：

```bash
hermes gateway setup
```

它会引导你选择 Weixin，然后进入扫码流程。这个时候必须你本人用手机微信扫码。

配置完成后，再让 Codex 测试：

```bash
hermes gateway run
```

然后你在微信里给 Hermes 发一句：

```latex
你好，请用一句话告诉我你已经接入微信。
```

如果能收到回复，说明微信入口基本通了。

这里有个坑要提前说：微信入口不一定像普通好友一样在所有客户端同步。手机微信通常更稳，电脑端微信有时可能搜不到或不同步。遇到这种情况，先用手机微信测试，不要一上来重装 Hermes。

## 装好以后，别问“你会什么”，直接派活
很多人接进微信以后，第一句还是问：

```latex
你会什么？
```

当然能问，但这很浪费。Hermes 最舒服的用法不是陪聊，而是派活。

比如你要写公众号文章，不要只说：

```latex
写一篇文章
```

这句话太空了。你可以这样说：

```latex
帮我写一篇公众号文章，主题是 Hermes Agent 新手安装。读者是没有技术背景但想折腾 AI 工具的产品经理。风格要口语化、有一点吐槽感，不要像官方文档。先给我 8 个标题，我选完标题后再写正文。
```

标题选完以后，再继续：

```latex
用第 3 个标题写完整初稿，2500 字左右。结构要清楚：先讲为什么要装，再讲小白怎么用 Codex 帮忙装，再讲微信怎么互动，最后讲安全提醒。命令要单独放代码块，每个命令后面用一句人话解释。
```

如果你要它改稿，可以说：

```latex
这版还是太像教程了，开头再尖锐一点，把“小白不懂终端但可以用 Codex 代装”的冲突写出来。不要改标题。
```

如果你要它整理资料，可以说：

```latex
先不要写正文，帮我查 Hermes 官方文档里关于 Gateway 和 Weixin 的部分，整理成 5 条适合放进文章的要点，并标出哪些是新手必须知道的。
```

你会发现，微信只是入口。真正的重点是，Hermes 能不能调用工具、读文件、跑命令、整理资料、写文章。

## 如果你懂终端，也可以走手动版
如果你本来就会终端，那当然可以直接装。

macOS / Linux / WSL2：

```bash
curl -fsSL https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.sh | bash
hermes model
hermes doctor
```

这几行的意思是：先用官方安装脚本安装 Hermes，再进入模型配置，最后跑一次体检。

如果安装后系统提示找不到 `hermes` 命令，可以先重开一个终端窗口；如果还是不行，再让 Codex 帮你检查 shell 配置。

Windows PowerShell：

```powershell
irm https://raw.githubusercontent.com/NousResearch/hermes-agent/main/scripts/install.ps1 | iex
```

Windows 用户如果后面要跑更多开发类任务，通常用 WSL2 会更稳。你可以直接让 Codex 判断：

```latex
我现在是 Windows。请先判断直接用 PowerShell 安装 Hermes 更合适，还是用 WSL2 更稳。先解释理由，再执行。
```

但对纯小白来说，手动版不是第一选择。更稳的路径还是先让 Codex 完成第一遍，再慢慢理解背后的命令。

## 几个坑，提前说清楚
**第一，网页聊天大模型不等于 Codex。**

普通 ChatGPT 网页、普通国产大模型网页，如果不能操作你的电脑，就只能告诉你怎么做，不能替你做。你需要的是 Codex Desktop 这类能读文件、能跑命令、能看到命令结果的工具。Cursor、Claude Code、Trae 这类能操作本地项目和终端的 AI IDE，也可以按同样思路使用。

**第二，权限不是越大越好。**

为了安装，Codex 确实需要执行命令。但如果这是你的主力电脑，里面有工作资料、合同、聊天记录、密钥文件，就不要一上来给它无限权限。先在空文件夹里安装，后续要访问哪个目录，再单独授权。

如果你的 AI IDE 提示是否开启“完全访问权限”，不要闭眼点同意。先确认两件事：你现在是不是在一个干净的安装目录里；它接下来是不是只需要创建 Hermes 相关文件和执行安装命令。只有当你明确知道自己在授权什么时，再扩大权限。

**第三，不要把 API Key 直接扔进聊天里。**

如果 Hermes 配模型时需要 API Key，让 Codex 引导你走安全输入流程，或者告诉你应该填在哪里。不要把密钥直接贴在聊天窗口里，更不要让它把密钥打印出来。

**第四，微信入口不是普通好友。**

Hermes 接微信背后可能是 Weixin / iLink bot 这类 bot 身份，不一定像普通好友一样在所有客户端同步。手机微信一般更稳，电脑端微信有时可能搜不到或不同步。遇到这种情况，先别重装，先用手机微信测试。

**第五，微信群不要一开始就押宝。**

普通微信群消息不一定会被交给 Hermes。最稳的测试方式是先私聊跑通，再研究群聊。

**第六，安装成功不等于可以乱用。**

Codex 和 Hermes 都能操作电脑，这是一把双刃剑。它们能帮你装工具、写文章、查资料，也可能因为权限太大看到不该看的文件。所以第一次完成验收后，建议立刻让 Codex 帮你做一件事：

```latex
我现在是在主力电脑上运行 Codex 和 Hermes，里面有工作资料和隐私文件。请帮我设计一个既方便又安全的使用边界，不要直接改系统，只给我方案。
```

## 最后说句实话
现在的小白真正需要学的不是每一条命令，而是怎么把任务交代清楚。

以前装一个开发工具，你得自己看文档、敲命令、排错。现在更现实的方式是：你把目标、边界、验收标准写成一个文件，让 Codex 替你执行。

这就是为什么我更推荐“安装任务书”这条路。

它不是炫技，也不是偷懒，而是更符合现在的工作方式：

> **人负责目标和判断，Codex 负责执行和排错。**
>

纯小白不必从终端开始。

先新建文件夹，写好任务书，丢给 Codex，让它帮你把 Hermes 装起来。或者更进一步，让 Codex 在干净目录里直接创建安装任务书，再按官方文档完成安装。

等 Hermes 真正在电脑里跑起来，真能在微信里回消息，真能帮你写文章、整理资料、执行任务时，你自然会理解：为什么这不是普通聊天机器人，而是一匹真的能开始干活的马。
