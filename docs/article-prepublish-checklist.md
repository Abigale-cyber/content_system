# 图文发布前检查清单

适用范围：阶段 1 主链路 `case-writer-hybrid` -> `generate-image` -> `wechat-formatter`

## 一、输入检查

- [ ] 已有明确的 `slug`
- [ ] 输入 brief 已保存到 `content-production/inbox/`
- [ ] 观点表达清楚，不是只有一个模糊标题
- [ ] 已说明目标读者是谁
- [ ] 已说明希望文章解决什么问题

## 二、正文检查

- [ ] 已生成 `content-production/drafts/{slug}-article.md`
- [ ] 标题明确，不空泛、不口号化
- [ ] 开头 3 段内能交代主题和价值
- [ ] 结构完整，至少有“问题/观点/案例/结论”中的 3 个部分
- [ ] 段落长度适中，适合公众号阅读
- [ ] 没有明显的 AI 套话、重复句、空洞总结
- [ ] 没有事实不清、案例来源不明的问题

## 三、配图检查

- [ ] 至少生成 1 张配图或信息图
- [ ] 图片文件已保存到 `content-production/ready/{slug}-img-*.png`
- [ ] 图片风格与正文主题一致
- [ ] 图片文字没有明显错别字
- [ ] 图片比例适合公众号插图使用

## 四、排版检查

- [ ] 已生成 `content-production/ready/{slug}-wechat.html`
- [ ] 仅对 Markdown 做了一次 `wechat-formatter` 排版
- [ ] 标题层级、加粗、列表显示正常
- [ ] 没有重复嵌套样式或明显空白异常
- [ ] 微信后台粘贴后预期可读

## 五、发布风险检查

- [ ] 没有敏感表述、侵权内容或未经核实的数据
- [ ] 若引用外部案例，已在文中交代来源或保留可追溯信息
- [ ] 没有泄露隐私、账号信息或内部敏感信息
- [ ] 如果是热点评论，观点边界清楚，不夸大结论

## 六、落盘与归档检查

- [ ] 输入素材、成稿、配图、HTML 至少 4 类产物都已落盘
- [ ] 同一篇内容只使用同一个 `slug`
- [ ] 没有出现 `final-final-v2` 之类重复版本命名
- [ ] 本次运行中遇到的问题已补充到 `docs/CLAUDE.md` 或本清单
