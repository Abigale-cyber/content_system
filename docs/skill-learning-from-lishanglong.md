## 一、补充进现有 skill 的内容

### 1. `humanizer-zh` — 补充去 AI 味检测规则

| 规则类型 | 具体内容 |
|----------|----------|
| 禁止词表 | 「首先、其次、最后、综上所述、总而言之、值得注意的是、不可否认」→ 标记为需替换 |
| 句子长度 | 超过 20 字的句子必须拆短（课程反复强调 15-20 字上限） |
| 书面语→口语 | 「因此」→「所以」、「此外」→「还有」、「然而」→「但是」、「由此可见」→删掉重写 |
| 开头去模板 | 检测到「大家好」「今天我要给大家分享」「众所周知」→ 直接标注为需重写 |
| 气口检测 | 每隔 2-3 句话检查是否有停顿/转折/提问，连续 4 句以上无喘气点 → 标注为节奏问题 |

课程来源：模块三「改稿五步法」「AI 辅助写作 6 步流程」「避坑清单」

### 2. `case-writer-hybrid` — 补充 6 种文章结构模板

写入 `references/` 目录，作为框架路由的候选集：

| 结构 | 适用场景 | 公式 |
|------|---------|------|
| 金字塔结构 | 观点类/科普类 | 结论先行 → 3 个论据 → 金句收尾 |
| 序列步骤结构 | 教程类 | 开场说明收益 → 逐步操作 → 总结预告 |
| 故事叙述结构 | 案例/经历类 | 开端 → 冲突 → 转折 → 结局 |
| 问答结构 | 辟谣/科普 | 抛问题 → 回答 → 举例 → 纠误 → 行动建议 |
| 对比结构 | 工具对比 | 展示 A → 展示 B → 数据对比 → 结论 |
| 环形首尾呼应 | 观点输出 | 开头金句/场景 → 展开论述 → 回到开头 |

路由逻辑：根据 brief 里的 topic 类型和 `论证方向` 自动匹配最合适的结构。

课程来源：模块三「6 种内容结构模版」

### 3. `case-writer-hybrid` — 补充 Hook/开头钩子模板

| 钩子类型 | 示例 |
|---------|------|
| 反常识型 | "我劝你现在别学 AI" |
| 痛点直击型 | "每天写周报花你 1 小时？" |
| 数字冲击型 | "3 天涨了 2000 粉" |
| 故事开头型 | "我朋友上个月被裁了，但昨天他请我吃了顿大餐" |
| 提问式 | "你知道 AI 已经能帮你相亲了吗？" |

**禁止开头**：「大家好」「今天我要给大家分享」「众所周知」

课程来源：模块三「爆款脚本公式 Hook→Introduction→Body→Summary」

### 4. `case-writer-hybrid` — 补充结尾三件套

写入 `references/hook-and-ending.md` 的结尾部分：

- 金句收束："记住，学 AI 不是选择题，是生存题"
- 引导互动："你觉得呢？评论区告诉我"
- 预告下条："明天我教你 XXX，记得来看"

课程来源：模块三「结尾模板」

### 5. `case-writer-hybrid` — 补充 critic 阶段的「三轮回改法」

目前 runtime.py 的 3 轮循环（writer→critic→humanizer→judge）每轮改什么不够明确。补充以下判断标准：

| 轮次 | 改什么 | 检查点 |
|------|--------|--------|
| 第一轮（结构） | 用户阅读逻辑 vs 你的写作逻辑 | 每段是否有明确结论？段落顺序是否按「问题→方案→案例→行动」排布？ |
| 第二轮（语言） | 朗读法：拗口就改 | 书面语→口语、长句→短句、去掉 AI 八股连词 |
| 第三轮（共鸣锚点） | 在关键转折处插入共鸣句 | "你有没有这种感觉……"、"说白了就是……"、检测是否纯论述无故事 |

课程来源：模块三「改稿五步法」「三轮回改法」

### 6. `news-collect` / `topic-research` — 补充选题四维打分

在输出的「写作决策」层增加四维评估：

| 维度 | 评分（1-5） | 说明 |
|------|------------|------|
| 热爱程度 | 你的表达意愿，能否持续输出 |
| 专业能力 | 你能不能讲清楚，比目标读者多 10% |
| 市场需求 | 受众够不够大，痛点是否真实 |
| 资源积累 | 你有没有案例和素材支撑 |

课程来源：模块二「万能选题公式」、加餐课 Mike 的打分框架

### 7. `wechat-formatter` — 补充标题优化 6 技法

在输出 HTML 时同时生成 3-5 个标题候选：

1. 简明扼要（15 字以内）
2. 用数字
3. 疑问句
4. 夸张但有底线
5. 直击受众
6. 悬念/反常识

课程来源：模块四「标题优化 6 技法」

### 8. `ai-frontier-radar` — 检查信源覆盖

课程提到的信息雷达渠道，逐一检查 ai-frontier-radar 是否已覆盖：

## 二、值得新建的 skill（2 个）

### 1. `script-writer-short` — 短视频脚本生成器

**定位**：和 `case-writer-hybrid`（公众号长文）并行，专门生成 1-2 分钟短视频口播脚本。

**理由独立**：短视频脚本的字数逻辑（200-300 字 = 1-2 分钟）、结构要求（Hook→Introduction→Body→Summary 四段式）、表达风格（口语化、节奏感强）和公众号长文完全不同。

**输入**：选题 + 定位信息 + 目标平台（视频号/抖音/YouTube）

**输出**：`content-production/drafts/{slug}-script.md`
- Hook（20-30 字）
- Introduction（30-40 字）
- Body（120-180 字，1-3 个要点，每个要点遵循「结论→举例→数据/收益」）
- Summary（30-40 字，金句 + 互动 CTA）
- 拍摄提示（是否需要出镜、背景建议、节奏标注）

**参考库**：
- 5 种 Hook 类型（反常识/痛点直击/数字冲击/故事开头/提问式）
- 故事三要素检查（人物 + 冲突 + 转折）
- 平台差异提示（视频号偏情绪、YouTube 偏结构）

课程来源：模块三「爆款脚本公式」「故事叙述法」

### 2. `topic-radar` — 热点→选题角度转化器

**定位**：在 `news-collect`（采集热点）和 `content-brief-builder`（构建 brief）之间，做轻量的「热点→选题角度」转化。

**收窄范围**：不做"灵感系统"（那是个人习惯），只做结构化的热点角度转化。

**输入**：一个热点事件/话题 + 你的定位信息

**输出**：3-5 个选题角度候选，每个包含：
- 角度描述（一句话）
- 对应赛道
- 三种通用选题公式的匹配（痛点+工具+结果 / 误解+反转+证明 / 低效动作+AI替代+效果对比）
- 推荐结构模板（6 种中的哪一种）
- 时效性判断（24h 内 / 48h / 常青）

**选题公式来源**：
- `痛点 + AI工具 + 具体结果`
- `误解 + 反转 + 证明`
- `低效动作 + AI替代 + 效果对比`

课程来源：模块二「灵感系统搭建」「热点七步法」「万能选题公式」

以下内容有价值但不足以独立成 skill，作为参考文件写入现有 skill 的 `references/` 目录。

### 1. 开头钩子生成 → `case-writer-hybrid/references/hook-templates.md`

5 种 Hook 类型 + 禁止开头列表 + 每种类型的 3 个示例。作为交互模式 Step 2 的参考库。

课程来源：模块三「Hook 开头钩子」

### 2. 故事注入方法 → `case-writer-hybrid/references/story-injection.md`

- 5 种故事来源：个人经历 > 粉丝故事 > 行业案例 > 假想场景 > 比喻故事
- 三要素检查：人物（有代入感）+ 冲突（有共鸣）+ 转折（有希望）
- 伪故事三段式：问题 + 行动 + 结果（没有真实素材时使用）
- 故事密度建议：每 300-500 字正文至少一个故事或具体案例

作为 critic 阶段的检查依据和交互模式 Step 3 的写作参考。

课程来源：模块三「故事叙述法」「改稿五步法」

### 3. 跨平台适配指南 → `docs/cross-platform-guide.md`

| 维度 | 视频号版 | YouTube 版 | 公众号版 | 小红书版 |
|------|---------|-----------|---------|---------|
| 时长/字数 | 1-2 分钟 | 5-15 分钟 | 2000-4000 字 | 300-800 字 |
| 风格 | 情绪驱动、朋友聊天 | 结构/原理/方法 | 观点+论证+案例 | 清单+干货+图 |
| 开头 | 3 秒情绪 Hook | 说明观众将学到什么 | 反常识/痛点钩子 | 标题即结论 |
| 结尾 | 金句 + 互动 CTA | 总结 + 预告 + 订阅 | 行动建议 + 金句 | 总结 + 互动 |

作为 `wechat-formatter`、`xiaohongshu-note-generator`、`script-writer-short` 共用的参考文件。

课程来源：模块四「一鱼两吃」

## 四、思维模型（存入知识库，不系统化）

以下内容属于认知/战略层面，不适合变成 skill，但值得作为知识资产保留：

1. **四差利润模型**：信息差 > 认知差 > 行动差 > 能力差。表达者比技术者稀缺。
2. **知识资产化**：不需要成为世界第一，只需要比目标客户多 10%。卖解决方案而非卖信息。
3. **杠杆思维**：趋势杠杆 + 产品/媒体杠杆 + AI 技术杠杆 + 资本杠杆。一个成功项目覆盖所有试错。
4. **定位公式**：`你是谁 + 你为谁服务 + 你提供什么独特价值`
5. **选题四维打分**：热爱程度 × 专业能力 × 市场需求 × 资源积累
