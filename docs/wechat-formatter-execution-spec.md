# `wechat-formatter` 执行说明

## 1. 这个 Skill 做什么

把 Markdown 成稿转换为适合微信公众号后台粘贴的 HTML。

当前阶段的定位非常明确：

- 它不负责写文章
- 它不负责补图
- 它只负责把主稿排成可发布格式

## 2. 输入

标准输入：

- `content-production/drafts/{slug}-article.md`

可选输入：

- 主题风格偏好
- 强调色偏好

## 3. 输出

标准输出：

- `content-production/ready/{slug}-wechat.html`

## 4. 执行步骤

1. 读取 Markdown 主稿。
2. 保留标题层级、段落、列表、引用等基础结构。
3. 转换为微信公众号兼容的 HTML。
4. 控制样式简洁，优先保证可读性。
5. 输出到 `ready/`。

## 5. 质量标准

- 标题层级清晰
- 段间距适中
- 列表、引用、加粗等格式显示正常
- 不出现重复嵌套样式
- 粘贴到微信后台后应保持可读

## 6. 建议提示方式

```md
请你扮演 `wechat-formatter`。

任务：
把这份 Markdown 主稿转换为微信公众号可粘贴的 HTML。

要求：
1. 保留原始结构，不改写正文内容
2. 样式简洁、适合公众号阅读
3. 保证标题、列表、引用、加粗显示正常
4. 不重复嵌套样式
5. 输出保存为 `ready/{slug}-wechat.html`
```

## 7. 本阶段最重要的约束

- 只接 Markdown，不接已经排好的 HTML
- 不在这里补内容、改结构、重写标题
- 若发现正文结构本身有问题，应回到 `case-writer-hybrid` 修，而不是在排版阶段硬修

## 8. 异常处理

| 异常 | 说明 | 处理方式 |
|------|------|----------|
| 输入已是 HTML | 上游可能重复排版 | 停止本步，先确认是否跳过 |
| 层级混乱 | Markdown 标题或列表写法不规范 | 回到正文修正后再排版 |
| 粘贴效果脏乱 | 样式过重或标签嵌套异常 | 收缩样式复杂度，优先简单模板 |
