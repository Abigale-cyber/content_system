# `generate-image` 执行说明

## 1. 这个 Skill 做什么

根据文章主题和关键论点，生成适合公众号使用的配图或信息图。

当前阶段 1 不要求大量图片，只要求：

- 至少 1 张可服务正文的主配图
- 图片风格统一
- 图片和文章核心观点一致

## 2. 输入

推荐输入来源：

- `content-production/drafts/{slug}-article.md`
- 或文章摘要 + 标题 + 关键论点

最少应给出：

- 文章标题
- 核心观点
- 1 到 3 个关键论点
- 希望图片类型

## 3. 输出

主输出：

- `content-production/ready/{slug}-img-1.png`

可选输出：

- `content-production/ready/{slug}-img-2.png`
- `content-production/ready/{slug}-img-3.png`

## 4. 当前推荐图片类型

阶段 1 优先级从高到低：

1. 信息图
2. 公众号插图
3. 封面感视觉图

不建议当前优先做：

- 纯装饰图
- 复杂长图卡片
- 视频分镜图

## 5. 执行步骤

1. 读取文章标题与摘要。
2. 提炼 1 个主视觉主题。
3. 选择图片风格：信息图 / 插画 / 封面感视觉。
4. 先生成 1 张主配图。
5. 检查图片是否真的能服务正文；不行再重生成。

## 6. 质量标准

- 读图就能感受到文章在讲什么
- 颜色和风格不能过杂
- 若有文字，必须短且无错别字
- 不要生成与正文无关的炫技图

## 7. 建议提示方式

```md
请你扮演 `generate-image`。

任务：
基于这篇文章的标题、核心观点和关键论点，生成 1 张适合公众号使用的配图。

要求：
1. 图片服务正文，不只是好看
2. 优先做信息图或具有结构感的插图
3. 画面聚焦一个主视觉，不要元素过多
4. 如果有文字，保持极简，确保无错别字
5. 输出结果保存为 `ready/{slug}-img-1.png`
```

## 8. 配图方向模板

你可以从 brief 中抽以下字段交给本 Skill：

- 文章主题
- 文章核心判断
- 想强调的 1 到 3 个关键词
- 禁止出现的视觉元素

## 9. 本阶段最重要的约束

- 先求“可用”，再求“惊艳”
- 先做 1 张主配图，不追求一次出完整图包
- 图片输出要能和 `wechat-formatter` 后的文章一起交付
